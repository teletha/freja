LabelHelper<C>

  • CJLabel

    the concrete label type returned by every helper, so chains keep the caller's type

  • ARXLabel

Fluent helpers for the settings declared by JLabel. The interface is bounded to JLabel, the class which owns these methods, so it works on any label subclass; colours, fonts and borders stay in StyleHelper and LayoutHelper, which are shared by every component.
