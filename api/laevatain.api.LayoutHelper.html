Fluent spacing helpers for the ARX panels. Implementing this interface lets a panel take its inset in the same chained expression which builds it, instead of exposing a mutable setter.

A margin is represented by an empty javax.swing.border.Border: Swing reserves the space inside the component, so the panel's background still extends behind it. Setting a margin replaces any border the panel already had; callers which need a visible border as well must install a compound border afterwards.

Applies an independent inset to each side. This is the single method which touches the border; the shorter overloads only normalise their arguments and delegate here.

The order matches java.awt.Insets (top, right, bottom, left), whereas BorderFactory#createEmptyBorder(int, int, int, int) takes top, left, bottom, right; the two middle values are swapped below.
