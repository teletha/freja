Fluent border helpers for the ARX components. Implementing this interface lets a component describe its spacing in the same chained expression which builds it, instead of exposing a mutable setter.

Swing gives a component a single border slot, so padding, the visible border and margin are composed into one border, from the outside in: margin, border, padding. All three reserve space inside the component; the background therefore reaches out behind them. Call #border(Border) first, then wrap it with #margin(int) and #padding(int): those two keep whatever border is already installed. A later border call replaces the whole composition.

Applies an independent margin to each side. The empty border is placed outside the border already installed, so a visible border and the padding inside it survive the call.

The order matches java.awt.Insets (top, right, bottom, left), whereas BorderFactory#createEmptyBorder(int, int, int, int) takes top, left, bottom, right; the two middle values are swapped below.

Sets a matte border with an independent width on each side, e.g. a single hairline on the left edge. The widths follow java.awt.Insets order (top, right, bottom, left) and a zero width suppresses that side. Like #border(Border), this replaces any previously composed margin and padding, so call it before those helpers.
