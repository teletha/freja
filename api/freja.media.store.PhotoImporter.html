placeholder(Pathfile, longmodifiedAt)AnalyzedPhoto

Pathfile

the unreadable file
longmodifiedAt

the file's modification time, or -1 to read it
AnalyzedPhoto

the placeholder analysis

Builds the analysis of a file whose pixels cannot be decoded.

The file still becomes a catalog row, so the user can find, select and delete it instead of it silently disappearing from the grid. Its dimensions are recorded as zero because they are unknown, and every row shares one small pre-encoded "broken image" thumbnail. The bytes are built once, when the first unreadable file needs them.
