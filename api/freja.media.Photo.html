Photo

  • Record

One photo managed by the library.

The record contains metadata only. The thumbnail bytes are loaded separately so that a view of ten thousand photos does not carry ten thousand images in memory.

isUnreadable()boolean

boolean

true when the original cannot be decoded

Whether the pixels of this photo could not be decoded when it was imported.

Such a file is still a catalog row: it has a generated placeholder thumbnail, and every operation except opening the original works on it. Unknown dimensions are the marker, because freja.media.store.Library records zero width and height for these rows.

Returns a dimensions label. Photos whose pixels could not be decoded have no known size, so they get a label instead of reporting "0 × 0".

isVideo()boolean

boolean

true for a supported video extension

Whether this row is a playable video file rather than a still image.

durationLabel()String

String

the formatted duration, or an empty string for still images

Returns the playback duration as m:ss.

archived()boolean

boolean

true for an archive entry

Whether this row is an image inside a ZIP or 7z archive rather than a file on disk. Such a row has a synthetic #path() and cannot be revealed or deleted on its own.

origin()Path

Path

an existing file, or the synthetic path for regular photos

The real file behind this row: an archive for indexed entries, the photo file otherwise. Use this for "reveal in Explorer" and similar operations which need an existing path.
