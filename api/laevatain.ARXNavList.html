A Windows 11-style navigation list: icon rows with a rounded selection wash, an optional trailing annotation, hover feedback, arrow-key navigation and an optional context menu.

Colours and fonts come from the ARX.* UI defaults rather than from a concrete theme class, so any host application can drive the look of the list by publishing those keys.

getMaximumSize()Dimension

Dimension

BoxLayout derives a component's maximum from its own layout manager, which caps this list at its preferred width and lets the parent centre it - the header and every row then drift to the right. Ask for the full column width while keeping the height rigid, so the list is stretched by its parent and never stretched apart by it.

Takes one row out of the list without touching the others. Rebuilding the whole list for a refresh replaces the panels under the pointer, which swallows clicks which are in flight.

align(ListStringorder)void

ListStringorder

Places the rows in the given order, reusing the row components which are already there. The order is left alone when it already matches, so a refresh which changes nothing keeps the components - and a click in flight - intact.
