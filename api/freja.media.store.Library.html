freja.media.store

Library

  • AutoCloseable

The SQLite-backed photo catalog.

A single connection is guarded by the intrinsic lock of this object. SQLite is fast enough for the reads the UI makes, and keeping one writer avoids SQLITE_BUSY between the scanner and the rest of the application. All thumbnails are stored in a separate table so browsing the catalog never reads megabyte-sized blobs by accident.
