freja.util

SmartTags

Derives tags from folder names. A folder whose name starts with one or more bracketed strings is tagged with them, e.g. 【旅行】(２０２４) 写真 yields 旅行 and 2024.

fromFolderName(Stringname)ListString

Stringname

a folder name
ListString

normalised tags, in the order they appear

Reads the bracketed groups at the beginning of a folder name.

normalize(Stringvalue)String

Stringvalue

the raw tag name
String

the normalised tag name, or an empty string when there is nothing usable

Normalises a tag: full-width letters and digits become half width, while Japanese kana stay full width, and surrounding whitespace is removed.
