The ARX scroll container: a borderless JScrollPane whose viewport follows the pane's own background and opacity. Plain Swing scroll panes regain a hairline border and an opaque default viewport on every look and feel change, which breaks the flat ARX surfaces; this component keeps the chrome flat across theme changes.

Horizontal scrolling is off and the wheel advances by one navigation row (28 pixels), matching ARXNavList. #setBackground(Color) and #setOpaque(boolean) propagate to the viewport, so the fluent helpers inherited from ComponentHelper style both layers at once.
