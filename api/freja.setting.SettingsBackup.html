freja.setting

SettingsBackup

Bulk export and import of the application's user preferences.

Freja keeps its settings in a handful of Java Preferences nodes - the theme, font, language and window layout under /freja, and the reusable components' language and chooser folders under /laevatain. Collecting those nodes into one properties file makes a profile portable; restoring it replaces their contents so stale values from the current machine cannot survive the import. Keys outside those two roots are never touched.
