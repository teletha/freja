Archives

Reads images inside ZIP and 7z archives without extracting them.

An archive is a container, not a photo. Its entries are indexed as virtual photos whose Photo#path() is a synthetic path below the archive, so all reads of the original bytes have to go through #read(Photo). The identity of an entry is its cleaned name, which keeps the catalog stable even when the archive was created on a machine with a different path separator.
