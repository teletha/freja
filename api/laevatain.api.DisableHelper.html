Fluent enabled-state helpers for the ARX components. They let a component take its initial state in the same chained expression which builds it, instead of exposing a mutable setter.

Disabling a Swing container does not clear the enabled flag of its children: they stop receiving input through the hierarchy but can still paint as enabled under some look and feels. This helper changes only the component it is called on; apply it to each child when the whole subtree must look disabled.

disabled(booleandisabled)C

booleandisabled

the disabled state
C

this component

Sets the disabled state. True disables the component, false enables it.

The name deliberately avoids disable() and enable(): java.awt.Component already defines deprecated void methods with those names, and a fluent override with a different return type would not compile.
