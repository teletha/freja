LangUtil

The localisation bridge for ARX components.

Interface text is written in the source as plain English and passed through I#translate, which resolves it against the language held in I#Lang: a sentence seen for the first time is translated online once and stored in a local bundle, later requests come from that cache. The result is a kiss.Variable, so widgets bound here follow a language change immediately and without restarting the application.

LANGUAGESListLanguage

The offered languages. Their names are written in their own language, the way every operating system lists them, so a bad translation can never hide the option the user is looking for. The first entry is the language the source sentences are written in.
