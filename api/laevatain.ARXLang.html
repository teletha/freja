ARXLang

The localisation bridge for ARX components.

Interface text is written in the source as plain English and passed through I#translate, which resolves it against the language held in I#Lang: a sentence seen for the first time is translated online once and stored in a local bundle, later requests come from that cache. The result is a Variable, so widgets bound here follow a language change immediately and without restarting the application.

Values are inserted with String#format placeholders (%d, %s) via #dynamic: mustache braces cannot be used, because the translation step substitutes those away before the text reaches the caller.

LANGUAGESListLanguage

The offered languages. Their names are written in their own language, the way every operating system lists them, so a bad translation can never hide the option the user is looking for. The first entry is the language the source sentences are written in.

bundleDirectory(Pathdirectory)void

Pathdirectory

the folder which will hold <language>.json

Pins where sinobu keeps its translation bundles. sinobu bakes its default - a lang folder relative to the working directory - into the environment cache while kiss.I is initializing, so handing it a default here would arrive too late; the resolved value is written into that cache directly instead. An explicit LangDirectory environment variable always wins.

bundleDirectory()Path

Path

The folder currently holding the translation bundles. A plain read: sinobu's two-argument lookup stores its default when the value is missing, so asking this first would lock the cache to the relative folder and make #bundleDirectory(java.nio.file.Path) too late.
