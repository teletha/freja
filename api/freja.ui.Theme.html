Theme

The visual language of the application.

The palette is expressed with dynamic colours, so every component which received a Theme colour is repainted with the new palette when the dark mode changes. FlatLaf updates the standard Swing components at the same time.

The hand tuned light palette, offered as a quick pick.

The hand tuned dark palette, offered as a quick pick.

themeId()String

String

The identifier of the active theme: a built-in id or an IntelliJ theme class name.

setTheme(Stringid)void

Stringid

an id from #availableThemes()

Switches to the theme with the given id and persists the choice. The look and feel goes in first, so a custom theme's own defaults can supply the shades the application paints with.
