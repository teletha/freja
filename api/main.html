Freja API Overview

This page provides a concise overview of the available APIs, including their purpose, key functionalities, and usage patterns. It serves as a starting point for developers to understand how to integrate and interact with the system effectively.

🛠️ Interface

LibraryScanner.Listener Receives scanner events. Methods may be called from a background thread.
PhotoInspector.Listener User actions initiated from the inspector.
ScanFoldersDialog.Listener Actions requested by this dialog.
Sidebar.Listener Callbacks for navigation actions.

🛠️ Functional Interface

PhotoViewer.Listener Receives changes made while the viewer is open.

🛠️ Class

ARXSearchField A reusable search field with a leading icon, placeholder, clear button and a debounced text callback. Fonts and colours come from the active FlatLaf theme.
ARXFileChooser A FlatLaf system chooser which opens where its owner last left it and stores the new location when it closes. Each dialog passes its own key so the positions do not mix.
ChooserLocations Remembers the last directory used by each file chooser, keyed by the dialog that owns it.
ARXButton A reusable FlatLaf button with a flat look, rounded corners and a hover style. All colours and the corner radius come from the active FlatLaf theme, so the button follows runtime theme changes.
SmartTags Derives tags from folder names. A folder whose name starts with one or more bracketed strings is tagged with them, e.g. 【旅行】(２０２４) 写真 yields 旅行 and 2024.
PathUtil Path normalization helpers shared by the database and the scanner.
ImageTransforms Pixel operations shared by thumbnail generation and the full screen viewer.
LibraryScanner Keeps the catalog in sync with the folders on disk.
PhotoInspector The details panel shown next to the thumbnail grid.
Theme The visual language of the application.
MainWindow The main application window.
Icons Small vector icons drawn with Java2D, so the application does not depend on image assets or on emoji fonts.
PhotoViewer A full screen photo viewer with zoom, pan, keyboard navigation and a slideshow.
PhotoGrid A virtualized, Picasa-like thumbnail grid.
ScanFoldersDialog Dialog for managing the folders the library watches and scans.
Sidebar The navigation sidebar.
Freja The application entry point.
PhotoImporter Decodes an image once and produces everything the library stores about it.
Exif A small, dependency-free reader for the EXIF block of a JPEG file.
Library The SQLite-backed photo catalog.

🛠️ Enum

ARXButton.Variant Predefined button roles, each mapped to FlatLaf UI defaults.
PhotoFilter.SortOrder How a result set is ordered.
PhotoGrid.GroupMode How the visible photos are divided by headers.
Sidebar.Mode The selected library view.

🛠️ Record

LibraryScanner.State A snapshot of the scanner state for the status bar.
LibraryStats Aggregate counters shown by the sidebar and status bar.
PhotoFilter A query against the photo library.
Folder A directory registered with the library.
Tag A label that can be attached to folders.
Photo One photo managed by the library.
PhotoImporter.AnalyzedPhoto The result of inspecting one image file.
Exif.Data The parsed values. All fields are optional.
Library.PhotoSave One catalog write waiting to be committed.
Library.FileStamp The file attributes a scan compares against the catalog.
Library.Thumbnail A thumbnail stored in the database.
