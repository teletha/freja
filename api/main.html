Freja API Overview

This page provides a concise overview of the available APIs, including their purpose, key functionalities, and usage patterns. It serves as a starting point for developers to understand how to integrate and interact with the system effectively.

🛠️ Interface

FileOperations.Listener no description
SettingsPanel.Listener Notifications sent back to the owner after a setting changed.
LibraryScanner.Listener Receives scanner events. Methods may be called from a background thread.
PhotoInspector.Listener User actions initiated from the inspector.
ScanFoldersDialog.Listener Actions requested by this dialog.
Sidebar.Listener Callbacks for navigation actions.

🛠️ Class

Language The localisation bridge for ARX components.
ARXCheckBox A check box whose caption can follow a Variable, so a translated option keeps its wording when the interface language changes.
ARXSettingsPane A Windows 11-style settings surface: an ARXNavList rail on the left and one continuous, scrollable document on the right. Every section registers a rail entry; choosing an entry glides the viewport to that section, scrolling keeps the rail in sync, and the search field in its own pane above the document narrows the whole page to the rows which answer to the query.
ARXSettingsPane.Section One anchored page of the document.
ARXSettingsPane.Block A block of a section which is not a card: a tile grid, a chart, anything with keywords.
ARXSettingsPane.Card A rounded card which re-lays itself around the rows a query leaves standing.
ARXSettingsPane.Row One searchable settings row.
ARXSearchField A reusable search field with a leading icon, placeholder, clear button and a debounced text callback. Fonts and colours come from the active FlatLaf theme.
ARXRadioButtonMenuItem A radio menu item whose caption can follow a Variable, mirroring ARXMenuItem.
ARXMenuItem A menu item whose caption can follow a Variable. Menus are built on demand, so a late translation still reaches an item which is already on screen.
ARXTextBinding Keeps one live text subscription for a component. Rebinding disposes the previous observer, so a component can switch sources - for example when its language changes - without leaking or being written by two translations at once.
ARXFileChooser A FlatLaf system chooser which opens where its owner last left it and stores the new location when it closes. Each dialog passes its own key so the positions do not mix.
ARXComboBox A combo box whose items follow live translations. Each source string is translated through I#translate(String, Object...) and the displayed item is replaced whenever that translation changes, while the selected index stays put.
ARXNavList A Windows 11-style navigation list: icon rows with a rounded selection wash, an optional trailing annotation, hover feedback, arrow-key navigation and an optional context menu.
ARXNavList.Row One row of the list. Kept public so callers can annotate or extend it.
ChooserLocations Remembers the last directory used by each file chooser, keyed by the dialog that owns it.
ARXTextField A text field whose contents can follow a Variable. Useful for values which are edited in place and also change elsewhere, such as the current name of a folder.
ARXToggle A Windows-style on/off switch. The state is delegated to Swing's toggle button model, so pressing, releasing, keyboard focus and the active look and feel all drive it the way they do for any other button; the component only paints the Fluent pill and glides the knob between the two positions.
ARXButton A reusable FlatLaf button with a flat look, rounded corners and a hover style. All colours and the corner radius come from the active FlatLaf theme, so the button follows runtime theme changes.
ARXWrapLabel A label which breaks its text into lines instead of asking for as much width as the longest line needs. A plain JLabel never wraps, so a long sentence widens the whole column without limit.
ARXMenu A menu whose caption can follow a Variable, mirroring ARXMenuItem.
ARXLabel A label whose caption can follow a Variable, e.g. the value returned by I#translate(String, Object...). Assigning a new variable replaces the previous subscription, so the caption stays in sync when the interface language changes.
PicasaTags Reads the folder-level description Picasa keeps in its hidden .picasa.ini file. Each whitespace-separated word of that description becomes a tag, so an old Picasa album's keywords survive a move to Freja.
SmartTags Derives tags from folder names. A folder whose name starts with one or more bracketed strings is tagged with them, e.g. 【旅行】(２０２４) 写真 yields 旅行 and 2024.
PathUtil Path normalization helpers shared by the database and the scanner.
ArchiveSettings The user's preference for indexing images inside ZIP and 7z containers.
ImageTransforms Pixel operations shared by thumbnail generation and the full screen viewer.
Mpv A small, synchronous wrapper around one libmpv instance.
MpvNative Downloads and loads the libmpv native library.
Win32Window Locates the native window behind a Swing component so libmpv can render into it.
FileBrowser Lists a directory lazily with psychopath and delivers the result on the EDT.
FileOperations Thin adapter from the file manager UI to psychopath's copy/move/delete/rename operations.
FileTab One vertical tab in the file manager: a pinned folder with its own navigation history.
FileManagerPanel A file manager with pinned folder tabs and a detailed file list, without a directory tree.
FileTabs The pinned folders of the file manager, persisted as a vertical tab strip.
Theme The visual language of the application.
MainWindow The main application window.
Icons Bundled SVG icons loaded from the classpath. The application stays offline-capable because the assets are shipped under src/main/resources/icons/mdi. During development, missing icons are fetched once from Iconify and cached in the source resource tree and in the compiled class path, so the next build bundles them and a packaged application never needs the network.
Freja The application entry point.
SettingsBackup Bulk export and import of the application's user preferences.
SettingsPanel Freja's settings page: the reusable ARXSettingsPane scaffold - searchable rail, anchored sections, glide scrolling and cards - filled with the application's appearance, font, language and system settings. Captions are written in English and translated by I#translate(String, Object...), so both the page and its search follow the language picked on the language section.
LibraryScanner Keeps the catalog in sync with the folders on disk.
PhotoInspector The details panel shown next to the thumbnail grid.
TagPicker A GitHub-issue-style label picker shown as a popover instead of a modal dialog: a new-label field, a searchable list of coloured labels and the current selection in one compact dropdown.
PhotoViewer A full-screen viewer with a video-site style overlay. The controls live in a separate translucent window, so fading them in or out never changes the size of the photo or video underneath.
PhotoGrid A virtualized, Picasa-like thumbnail grid.
FolderList The folder rail of the library, built on JList so only the rows inside the viewport are painted. A library which discovers ten thousand directories builds no components for the rows which are scrolled away: the model keeps plain Folder records and the renderer is one shared cell.
ScanFoldersDialog Dialog for managing the folders the library watches and scans.
TagManager A dialog for creating, renaming and removing tags. Tags are colour-coded and searchable, names can be edited in place, and selected rows can be renamed with a preview or removed together.
ThumbnailCache A bounded in-memory cache of decoded thumbnails with background loading.
Sidebar The navigation sidebar: a library list built from the reusable ARXNavList and the registered folders, which use the virtualized FolderList so a library with tens of thousands of directories paints only what the viewport shows. Captions are bound to live translations from I#translate(String, Object...).
PhotoImporter Decodes an image once and produces everything the library stores about it.
Exif A small, dependency-free reader for the EXIF block of a JPEG file.
VideoImporter Produces the catalog entry of a video: a still frame for the thumbnail plus the dimensions and duration reported by libmpv.
Archives Reads images inside ZIP and 7z archives without extracting them.
LibraryTasks Runs catalog work on a dedicated background thread and returns results through a UI dispatcher.
Library The SQLite-backed photo catalog.

🛠️ Enum

ARXButton.Variant Predefined button roles, each mapped to FlatLaf UI defaults.
AppIcon The window icons Freja can switch between in the settings page. Each design is an SVG in icons/app, rendered by FlatSVGIcon at the exact size the caller asks for. This keeps the same vector pipeline as the rest of the interface and lets FlatLaf produce crisp variants for small sizes and HiDPI screens instead of shrinking a single 128px bitmap.
PhotoFilter.SortOrder How a result set is ordered.
PhotoGrid.GroupMode How the visible photos are divided by headers.
Sidebar.Mode The selected library view.

🛠️ Record

Language.Supported A language the interface can be shown in.
ARXSettingsPane.Text A caption with its English origin kept for search. The displayed wording follows a live translation, while the origin stays stable so a query finds a row in every language.
FileBrowser.Entry One row of the file list.
Theme.Preview The handful of shades that stand for a theme in the appearance picker.
Theme.ThemeInfo A theme the user can pick: an identifier, a display name and whether it is dark. Built-ins carry a short id, IntelliJ themes their look and feel class name.
LibraryScanner.State A snapshot of the scanner state for the status bar.
LibraryStats Aggregate counters shown by the sidebar and status bar.
PhotoFilter A query against the photo library.
Folder A directory registered with the library.
Tag A label that can be attached to folders.
Photo One photo managed by the library.
PhotoImporter.AnalyzedPhoto The result of inspecting one image file.
Exif.Data The parsed values. All fields are optional.
Archives.Entry One image entry of an archive.
LibraryTasks.DeleteResult Outcome of a "delete from disk" request: successfully removed files and failures.
Library.PhotoSave One catalog write waiting to be committed.
Library.FileStamp The file attributes a scan compares against the catalog.
Library.Thumbnail A thumbnail stored in the database.
