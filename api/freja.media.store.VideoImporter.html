VideoImporter

Produces the catalog entry of a video: a still frame for the thumbnail plus the dimensions and duration reported by libmpv.

analyze(Pathfile, longmodifiedAt)AnalyzedPhoto

Pathfile

a video file
longmodifiedAt

the file's modification time, or -1 to read it
AnalyzedPhoto

the analysis with the video duration in milliseconds
IOException

Analyzes a video file with libmpv.

failed(Pathfile, longmodifiedAt)AnalyzedPhoto

Pathfile

the unreadable video
longmodifiedAt

the file's modification time, or -1 to read it
AnalyzedPhoto

the retry analysis

Builds the catalog entry of a video whose analysis failed. A negative duration marks the row for re-import on the next scan, so a transient libmpv failure does not become permanent.
