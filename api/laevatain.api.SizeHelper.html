Fluent sizing helpers for the ARX components. They replace repeated setPreferredSize calls in constructor chains and make the intent of a fixed axis explicit.

A layout manager can stretch or shrink a component unless its minimum and maximum agree with the preferred size, so #fixedWidth(int) and #fixedHeight(int) set all three together. Passing null to a size helper restores the look and feel's default. Dimensions are copied on the way in, so a caller cannot change a component later by mutating its own Dimension.
