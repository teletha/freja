LibraryTasks

  • AutoCloseable

Runs catalog work on a dedicated background thread and returns results through a UI dispatcher.

All UI-originated library access goes through this class. The single task thread serialises UI writes with each other; the Library lock still serialises them with the scanner. Results are always handed back through the dispatcher supplied by the caller (for example Swing's SwingUtilities::invokeLater), never on the task thread itself.
