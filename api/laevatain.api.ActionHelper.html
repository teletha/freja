Fluent listener registration. The addXxxListener methods are declared by Component and its subclasses and all return void, so a class method would win over an interface default with the same signature; the helpers therefore use onXxx names instead.

Listeners which only some components support are guarded by type checks and are no-ops on unsupported components, so one interface can be shared by every component.
