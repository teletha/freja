scale(BufferedImagesource, intmaxSize)BufferedImage

BufferedImagesource

the source image
intmaxSize

the maximum length of either edge
BufferedImage

the scaled image

Scales an image down while keeping its alpha channel intact.

The resampling is done by imagify's Catmull-Rom filter. Catmull-Rom is sharper than Java2D's default bicubic interpolation and is the algorithm imagify uses as its own default.

downscale(BufferedImagesource, intmaxSize)BufferedImage

BufferedImagesource

the decoded image
intmaxSize

the longest edge after this pass
BufferedImage

the reduced image, or the source when it is already small enough

Reduces an image to at most maxSize pixels on the longest edge with a cheap, progressive Java2D pass.

This is intended as a pre-pass before a high quality resampler. Running CATROM directly on a 12 MP photo allocates several large full-resolution arrays, while halving the image a few times first leaves only a few hundred pixels for the final filter. The aspect ratio and any real transparency are preserved.

hasTransparency(BufferedImageimage)boolean

BufferedImageimage

the image
boolean

true when the alpha channel actually carries transparency

Tests whether an image contains at least one pixel which is not fully opaque.

Decoders frequently return an ARGB image for an opaque source, so the presence of an alpha channel alone is not enough.

toOpaque(BufferedImagesource)BufferedImage

BufferedImagesource

an image whose pixels are all opaque
BufferedImage

an opaque RGB image

Converts an image to an opaque RGB one with a straight blit.

Decoders such as jpegli always return an image whose alpha channel is fully opaque. For those images #flatten(BufferedImage, int, Color) only pays for bicubic interpolation and anti-aliasing setup that cannot change a single pixel. A source copy with AlphaComposite#Src is the same blit without those hints. #hasTransparency(BufferedImage) does not have to be called first when the caller already knows the pixels are opaque.
