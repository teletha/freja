Freja's settings page: the reusable ARXSettingsPane scaffold - searchable rail, anchored sections, glide scrolling and cards - filled with the application's appearance, font, language and system settings. Captions are written in English and translated by I#translate(String, Object...), so both the page and its search follow the language picked on the language section.
