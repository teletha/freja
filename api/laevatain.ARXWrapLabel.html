A label which breaks its text into lines instead of asking for as much width as the longest line needs. A plain JLabel never wraps, so a long sentence widens the whole column without limit.

The breaking itself is left to Swing: this is a read-only text area with word wrapping turned on, which measures its height against the width it actually has. The component is only dressed up as a label - transparent, borderless, unfocusable - its maximum height pinned, because a vertical BoxLayout would otherwise stretch it across the leftover room in the row, and its caret made deaf to the viewport, because a caret otherwise drags the scroll pane around.
