VideoThumbnailSettings

The user's preference for the position from which a video's catalog thumbnail is taken.

The value is a number of seconds from the start of the clip. Zero keeps the very first frame; any other value is clamped to the middle of shorter clips so the thumbnail never lands in the closing credits. The preference lives under /freja, so freja.setting.SettingsBackup includes it in exported profiles.

DEFAULT_SECONDSint

The thumbnail position used when the user has not chosen one: three minutes in.

MIN_SECONDSint

The earliest position; zero asks for the first frame without seeking.

MAX_SECONDSint

The latest position the settings control offers.
