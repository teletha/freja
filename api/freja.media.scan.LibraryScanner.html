freja.media.scan

LibraryScanner

  • AutoCloseable

Keeps the catalog in sync with the folders on disk.

A scan walks the folder tree and only decodes files whose size or modification time changed. While the application is running, a WatchService catches new, changed and deleted files, and a periodic sweep repairs anything the platform watcher missed. Scans and watch events share one path-level guard, so the same image is never imported twice at the same time.
