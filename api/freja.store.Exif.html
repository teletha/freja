Exif

A small, dependency-free reader for the EXIF block of a JPEG file.

The application only needs a handful of tags, so this reads the TIFF structure directly instead of pulling in a general purpose metadata library. Anything malformed is treated as absent: a damaged camera file must never stop the library from being scanned.

read(Pathfile)Data

Pathfile

an image file
Data

the metadata, or Data#EMPTY when the file is not a JPEG or has no EXIF block

Reads the EXIF block of a file.

read(bytedata)Data

bytedata

a complete JPEG file
Data

the metadata, or Data#EMPTY when there is no usable EXIF block

Reads the EXIF block from an in-memory JPEG, which is what a scan already has after reading the file for decoding. It avoids opening the same file a second time.
