freja.media

MpvNative

Downloads and loads the libmpv native library.

Freja does not ship the binary. On first use it is downloaded from the official mpv release into the application data directory and verified against a pinned SHA-256. A failed download is not fatal: video support stays unavailable for the rest of the process and is retried on next start. Use -Dfreja.mpv.path=<directory> to point at an already extracted libmpv-2.dll.
