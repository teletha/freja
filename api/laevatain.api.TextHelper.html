    the concrete text component type returned by every helper, so chains keep the caller's type

  • ARXWrapLabel

Fluent helpers for text components: editing, the caret and the wrapping flags of a text area. The text-area-only settings check the component type and are no-ops on a plain text field, so every JTextComponent can share this interface.

editable(booleaneditable)C

booleaneditable

true to allow editing
C

this component

Sets whether the text can be edited. Read-only labels and viewers turn this off.

caret(Caretcaret)C

Caretcaret

the caret to install, or null for none
C

this component

Replaces the caret. A read-only component can install a caret which never scrolls the viewport.

lineWrap(booleanwrap)C

booleanwrap

true to wrap lines
C

this component

Enables word wrapping, but only on a JTextArea; other text components ignore it.

wrapStyleWord(booleanwrap)C

booleanwrap

true to wrap at words
C

this component

Wraps at word boundaries instead of mid-word, but only on a JTextArea.
