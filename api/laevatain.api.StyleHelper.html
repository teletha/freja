Fluent style helpers for the ARX components. A component implements this alongside LayoutHelper so its colours, text and visibility can be set in the same chained expression which builds it.

Each helper changes only the property it names: setting the family keeps the current style and size, and setting the size keeps the current family and style. The size is used as given; a host which supports a user-selected scale should scale the value before calling #fontSize(int). Visibility is a style concern here, while the enabled state lives in DisableHelper.
