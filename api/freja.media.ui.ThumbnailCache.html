ThumbnailCache

  • AutoCloseable

A bounded in-memory cache of decoded thumbnails with background loading.

The cache key includes the file modification time, so a photo which is edited on disk gets a fresh entry instead of keeping the stale thumbnail.

Decodes the first thumbnails of a view before the grid paints it. This runs on the refresh thread, so the first frame already has images instead of showing empty cells for a moment. Only a bounded prefix is warmed: scrolling still loads the rest lazily.
