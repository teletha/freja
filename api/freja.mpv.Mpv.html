Mpv

A small, synchronous wrapper around one libmpv instance.

The wrapper is UI independent on purpose: it can produce a still frame for the catalog as well as drive a player surface later on. Only one thread may poll events for an instance, which is why #load(Path) and #screenshot(Path) are synchronous.
