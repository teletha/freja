Fluent helpers for the child list every panel inherits from Container. The bound is Container, the class which actually implements add and remove, so panels and compound components can share these methods.

Swing's add methods return void and a class method always wins over an interface default, so they cannot be turned into fluent methods under the same name. These helpers use distinct names for the chainable variants instead.

children(Componentcomponents)C

Componentcomponents

the children to add
C

this container

Adds components in order, e.g. the rows assembled by a panel constructor.

removeChildren()C

C

this container

Removes every child. A panel which rebuilds its content calls this before adding new rows.
