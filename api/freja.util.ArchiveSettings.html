ArchiveSettings

The user's preference for indexing images inside ZIP and 7z containers.

Scanning archives is on by default, so a library which contains photo archives shows their contents on the first run. Turning it off stops new entries from being indexed; the next full scan also removes rows which were indexed from archives previously.

scanArchives()boolean

boolean

true unless the user turned the option off

Whether the scanner should look inside compressed files.

scanArchives(booleanenabled)void

Remembers the choice for this and future sessions.
