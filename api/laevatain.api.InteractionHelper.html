Fluent helpers for the small interaction settings every control needs: pointer shape, tooltip, keyboard focus and a component name. Keeping them in one interface lets a constructor describe a control in a single expression instead of scattering setters through the body.

clientProperty(Objectkey, Objectvalue)C

Objectkey

the property key
Objectvalue

the property value, or null to clear it
C

this component

Sets a client property, e.g. a FlatLaf styling key. Keeping this in the chain lets a field initializer describe all of its static settings in one expression.

cursor(Cursorcursor)C

Cursorcursor

the cursor to show over this component
C

this component

Sets the pointer shape. Null restores the parent's cursor.

handCursor()C

C

this component

Shows the hand pointer used by clickable rows and buttons.

tooltip(Stringtext)C

Stringtext

the tooltip, or null for none
C

this component

Sets the tooltip text. Null removes the tooltip and unregisters its timer.

focusable(booleanfocusable)C

booleanfocusable

true to accept focus
C

this component

Sets whether the component can take the keyboard focus. Display-only labels and renderers should refuse it so Tab lands only on actionable controls.

name(Stringname)C

Stringname

the name, or null for none
C

this component

Sets the component name used by accessibility tools and UI tests.
