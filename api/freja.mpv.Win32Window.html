Win32Window

Locates the native window behind a Swing component so libmpv can render into it.

Only the two FindWindow variants are needed: the viewer has a unique title, and its heavyweight canvas has the well-known SunAwtCanvas class name. This avoids reflecting into JDK internals and the extra --add-exports flag that would require.

window(Stringtitle)long

Stringtitle

the exact window title
long

the native window handle, or zero when not found

Finds a top-level window by its title.

child(longparent, StringclassName)long

longparent

the parent window handle
StringclassName

the window class, e.g. SunAwtCanvas
long

the native window handle, or zero when not found

Finds the first child window with the given class name.
