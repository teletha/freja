The window icons Freja can switch between in the settings page. Each design is an SVG in icons/app, rendered by FlatSVGIcon at the exact size the caller asks for. This keeps the same vector pipeline as the rest of the interface and lets FlatLaf produce crisp variants for small sizes and HiDPI screens instead of shrinking a single 128px bitmap.

The selected design lives in Preferences under /freja/ui, so the settings backup exports and imports it along with the rest of the profile.

PINWHEELAppIcon

The original four-curved-blade pinwheel with a small house, inspired by Picasa.

APERTUREAppIcon

A circle divided into six equal coloured sectors, like a camera shutter.

TILESAppIcon

Four rounded colour tiles on a white rounded square.

FILMAppIcon

A strip of film with sprocket holes and four coloured frames.

SQUAREAppIcon

A small four-blade pinwheel held inside a rounded square, shown as "Flower".
